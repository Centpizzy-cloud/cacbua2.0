## Process note

Each future publication should follow the same pattern established by Publication 001:
fact-check every claim against primary/government sources before writing, keep CACBUA's
own analysis clearly separated from sourced data, source and license-verify any photography
before use (see `docs/image-sources.md`), and get CACBUA institutional sign-off before
treating a draft as a published position.
